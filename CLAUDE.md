# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Kakebo is a Japanese household ledger app for Android, written in Flutter. `README.md` (in Italian) is the reference for structure, localization and asset tools; this file covers what you need beyond it.

## Commands

Flutter is not on the shell PATH. The SDK lives at `C:\Users\aless\develop\flutter\bin`, the same path as `flutter.sdk` in `android/local.properties`. Prepend it first, e.g. in PowerShell: `$env:Path = "C:\Users\aless\develop\flutter\bin;" + $env:Path`.

```sh
flutter gen-l10n            # after editing lib/l10n/*.arb (generated/ is committed; never edit it by hand)
flutter analyze
flutter test
flutter test test/features/navigation_test.dart --plain-name "swiping left"   # a single test
dart format -l 160 <files>  # the code is formatted at width 160; the default 80 would reflow everything
flutter build apk --release # signed with debug keys (no release keystore yet)
flutter run --dart-define=DEMO=true --dart-define=TODAY=2026-09-24T21:30   # design demo data, fixed clock
flutter test tool/screenshots_test.dart   # every screen, top and bottom, into screenshots/<screen>/ (not in the normal suite)
```

To check a UI change visually, run the screenshot tool and look at the PNGs. It renders with the real fonts and art; add a row to `_shots` for a new screen or state.

## Architecture

- **State.** There is one `Kakebo` `ChangeNotifier` (`lib/state/kakebo.dart`) for the whole app.
  - Its `notifyListeners` override writes the entire state as one JSON blob through `KakeboStorage`. Mutate through `app.update(() => ...)` so every change is saved.
  - `refresh()` redraws without saving.
  - The JSON keys, `read`/`toJson` and the backup format must stay compatible with data already on phones. When you add a field, give it a default in `read` (see `flags`, which merges saved values over the defaults).
- **Time.** Use `Kakebo.clock`, never `DateTime.now()` directly. Tests set it and reset it in `tearDown`; `--dart-define=TODAY` sets it for demos.
- **Money model.** Several numbers look alike but measure different things, so don't merge them:
  - The budgeting month is a `Period` starting on `monthStart`, not the calendar month.
  - `available` = income − fixed costs − savings goal; `left` = available − spent.
  - `onTrack` = income − fixed − spent, i.e. the savings goal is still included.
  - On screen `onTrack` is always "Residuo attuale" (`tr.residualNow`) and `left` is "Ti restano"; keep one name per number.
  - `bloomed` (the branch) measures spending *pace*. It must never be turned into money.
- **Navigation.** No Navigator routes: screens switch on the string `app.screen`.
  - `app/root.dart` shows `onboarding`, `monthStart` and `thought` full screen. Everything else goes through `app/shell.dart`.
  - The Shell draws the greeting header, the pinned tabs (`home`, `ledger`, `journal`, `calendar`, with swipe between them), the persistent add button, plus `review` and `settings`.
  - Android back is mapped in `Root._back`.
- **Scope.** Widgets read state with `AppScope.watch` in build and `AppScope.read` in callbacks. Modal sheets are wrapped in a new `AppScope` (see `openAdd`).
- **Layers.** Models (`lib/model/`) import no UI and no translations. Pillar colours, art and names are presentation extensions in `lib/shared/theme/`.
- **Styling.** Colours are written as OKLCH through `ok(l, c, h)` (`shared/theme/color.dart`), matching the CSS design tokens. Text uses `serif()` (Shippori Mincho) and `sans()` (Zen Kaku Gothic New) from `tokens.dart`, not Material text themes.
- **Localization.** Use the global `tr` (`lib/l10n/localization.dart`). The ARB files are flat, so numbered keys are regrouped into lists by the `Lists` extension (pillars, steps, `phraseMeanings`, ...). Italian (`app_it.arb`) is the template.
- **Daily sayings.** The original and romaji are in `phrases` (`shared/theme/seasons.dart`); meaning and source (only for quotations) are `phraseN` / `phraseNSource` in the ARBs. Add a new saying in all three places. A test checks that the lengths match.

## Fonts and art

- **Fonts are subsets.** They contain only the characters used in `lib/` and the ARBs.
  - Any new Japanese character (or new language) needs `python tool/fonts.py <dir>`, run on the full TTFs from github.com/google/fonts (`ofl/shipporimincho`, `ofl/zenkakugothicnew`); it needs `fonttools`.
  - Neither font has macron vowels (ō, ū), so romaji uses the circumflex (ô, û).
- **Runtime art is baked.** `assets/art/*.webp` is generated by `python tool/art.py` from the masters in `assets/src/botanical/` and `assets/src/prints/` (the intro's Hiroshige prints, cropped and brought to one saturation). `paper.webp` is tinted to the app's `bg`, so the backdrop can fade without a colour shift. Edit the masters and re-bake; don't edit the WebP files.

## Testing notes

- Tests call `setUpAll(initL10n)` and `setLocale(const Locale('it', 'IT'))`, then look up Italian strings.
- Widget tests render with the Flutter test font, whose glyphs are wider than the real ones. Layouts can overflow at 360 px in tests even when they fit on a device, so make text in rows `Flexible`/`Expanded` instead of loosening the test.
- `audioplayers` has no plugin in tests, so anything that shows the breathing animation (`Thought` before writing) throws `MissingPluginException`.
